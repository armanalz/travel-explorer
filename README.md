# Travel Explorer 🌍

A responsive travel landing page built with HTML, CSS, and vanilla JavaScript.

This project showcases modern frontend development techniques, responsive layouts, interactive UI elements, and smooth animations without relying on external JavaScript frameworks.

## 🔗 Live Demo

[View Live Website](https://armanalz.github.io/travel-explorer/)

## ✨ Features

- Responsive layout for desktop, tablet, and mobile devices
- Mobile navigation menu with animated hamburger icon
- Sticky navigation bar using the Intersection Observer API
- Interactive travel planning section
- Destination cards built with CSS Grid
- Smooth scrolling and hover animations
- Progressive loading of the hero background image

## 🛠 Technologies

- HTML5 – Semantic page structure
- CSS3 – Flexbox, Grid, media queries, transitions, and animations
- JavaScript (ES6+) – DOM manipulation and event handling
- Git & GitHub – Version control
- GitHub Pages – Deployment

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/armanalz/travel-explorer.git
```

Open the project folder and launch index.html in your browser.

No installation or build process is required.

## 📌 Project Scope

Travel Explorer is a frontend demonstration project. Search and booking controls are visual UI elements and are not connected to a backend or reservation service.
